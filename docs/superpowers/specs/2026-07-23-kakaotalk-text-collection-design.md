# 카카오톡 대화·사진 수집 설계

## 목적

`KakaoTalk_20260723_2112_31_353_group.txt`에서 사람이 작성한 대화를 구조화하고 카카오톡 PC에서 사진 원본을 내려받아, 이후 인공지능 요약·검색·통계와 대화 타임라인 형태의 아카이브 웹페이지 제작에 사용할 수 있게 한다.

## 수집 범위

보존 항목:

- 메시지 작성 날짜와 시간
- 작성자 닉네임
- 여러 줄을 포함한 메시지 본문
- 본문에 포함된 URL
- `파일: 파일명` 형태의 파일 공유 기록
- 채팅방에서 다운로드할 수 있는 사진 원본
- 사진이 공유된 날짜·시간·닉네임과 같은 시각 내 순서

제외 항목:

- `동영상`
- `이모티콘`
- 채팅방 초대·퇴장 등 작성자와 시각이 없는 시스템 메시지

답장 메시지는 원본 TXT에 표현된 본문 형태를 그대로 보존한다. 원본 TXT는 수정하지 않는다.
첨부 문서 원본은 이번 범위에 포함하지 않고 `파일: 파일명` 기록만 보존한다.

## 파싱 규칙

1. `--------------- YYYY년 M월 D일 요일 ---------------` 형식의 구분선으로 현재 날짜를 설정한다.
2. `[닉네임] [오전/오후 H:MM] 본문` 형식의 줄에서 새 메시지를 시작한다.
3. 다음 메시지 또는 날짜 구분선이 나오기 전까지의 줄은 현재 메시지 본문에 줄바꿈으로 결합한다.
4. 오전·오후 시각을 24시간제로 변환하고 `Asia/Seoul` 기준 ISO 8601 시각을 생성한다.
5. 본문 전체가 `사진`이면 이미지 메시지로 보존하고, 다른 제외 항목과 정확히 일치하면 해당 메시지를 제외한다.
6. 작성자·시각 형식이 없는 줄은 시스템 메시지로 기록하지 않는다. 단, 이미 시작된 메시지의 연속 줄은 본문으로 보존한다.
7. 본문 URL은 원문을 유지하면서 별도 배열로도 추출한다.
8. 각 메시지에는 원본 등장 순서대로 안정적인 ID를 부여한다.
9. 같은 닉네임과 같은 시각에 여러 사진이 있으면 원본 등장 순서대로 `image_sequence`를 부여한다.

## 사진 수집 및 연결

1. 텍스트 파서가 먼저 사진 메시지 201개의 메시지 ID, 날짜, 시간, 닉네임, 순서를 `output/images.jsonl`에 `pending` 상태로 생성한다. 이 중 15건은 `사진 N장` 앨범이므로 예상 사진 파일은 총 249개다.
2. Computer Use로 카카오톡 PC의 해당 채팅방 서랍에서 사진 목록을 연다.
3. 사진을 오래된 순서에서 최신 순서로 확인하고, 월 단위 작업 묶음으로 다운로드한다.
4. 대화 시각과 확실히 연결되는 사진은 대응하는 이미지 메시지 ID를 사용해 `assets/images/YYYY-MM/msg-000001-01.<확장자>` 형식으로 저장한다.
5. 저장 후 파일 크기와 SHA-256 해시를 기록하고 상태를 `downloaded`로 변경한다.
6. 같은 시각에 여러 사진이 있으면 카카오톡에 표시된 시각 내 순서와 TXT의 등장 순서를 대조한다.
7. 다운로드할 수 없거나 대응 관계가 확실하지 않은 사진은 임의로 연결하지 않고 각각 `unavailable` 또는 `needs_review`로 남긴다.
8. 중단 후 재실행할 때 `downloaded` 항목은 건너뛰고 미완료 항목부터 계속한다.

카카오톡이 저장하는 원본 파일명 시각은 전송 시각이 아니라 촬영·생성 시각일 수 있다. 따라서 TXT의 전송 시각과 일치하는 경우만 자동 연결하고, 내려받기에는 성공했지만 연결 근거가 부족한 고유 파일은 `assets/staging/`과 `output/downloaded-files.jsonl`에 `unresolved`로 보존한다.

카카오톡 화면 구조가 예상과 다를 수 있으므로 첫 사진 3개를 시험 수집하여 파일 저장, 순서, 메시지 연결을 검증한 후 전체 수집을 진행한다.

## 출력 파일

### `output/messages.jsonl`

한 줄에 한 메시지를 기록한다.

필드:

- `id`: `msg-000001` 형태의 메시지 ID
- `timestamp`: Asia/Seoul 오프셋이 포함된 ISO 8601 시각
- `date`: `YYYY-MM-DD`
- `time`: `HH:MM`
- `nickname`: 카카오톡 표시 닉네임
- `text`: 줄바꿈을 보존한 본문
- `urls`: 본문에서 추출한 URL 배열
- `kind`: `text`, `image`, `file` 중 하나
- `is_file_share`: 본문이 `파일:`로 시작하는지 여부
- `image_id`: 이미지 메시지이면 대응하는 이미지 ID
- `source_line`: 원본 메시지 시작 줄 번호

### `output/conversation.md`

날짜별 제목 아래에 `HH:MM 닉네임`과 메시지 본문을 배치한다. 인공지능에 직접 제공하거나 사람이 검토하는 용도다.

### `output/participants.json`

닉네임별 다음 정보를 기록한다.

- 메시지 수
- 첫 메시지 시각
- 마지막 메시지 시각

닉네임은 원문 그대로 보존하며 임의로 합치거나 실명화하지 않는다.

### `output/images.jsonl`

사진 메시지 한 건당 다음 정보를 기록한다.

- `image_id`
- `message_id`
- `timestamp`
- `nickname`
- `image_sequence`
- `status`: `pending`, `downloaded`, `unavailable`, `needs_review`
- `local_path`
- `original_filename`
- `extension`
- `byte_size`
- `sha256`
- `collected_at`

### `assets/images/YYYY-MM/`

카카오톡 PC에서 내려받은 사진 원본을 월별로 저장한다. 실제 파일 확장자를 유지하고, 메시지 ID 기반 파일명을 사용하여 대화 데이터와의 연결이 끊어지지 않게 한다.

### `output/collection-report.md`

다음을 기록한다.

- 원본 파일명과 수집 시각
- 수집된 메시지 수
- 참여 닉네임 수
- 추출된 URL 수
- 파일 공유 기록 수
- 발견한 사진 메시지 수
- 다운로드·이용 불가·검토 필요 상태별 사진 수
- 유형별 제외 건수
- 파싱하지 못한 후보 줄과 원본 줄 번호

## 구성

- `scripts/collect_chat.py`: 명령행 진입점과 파일 입출력
- `scripts/kakao_parser.py`: 날짜·메시지·연속 줄 파싱
- `scripts/image_manifest.py`: 사진 수집 상태, 경로, 해시 관리
- `tests/test_kakao_parser.py`: 대표 형식과 예외 사례 테스트
- `output/`: 생성 결과
- `assets/images/`: 내려받은 사진 원본

수집기는 Python 표준 라이브러리만 사용하여 별도 패키지 설치 없이 실행할 수 있게 한다.

## 오류 처리

- 입력 파일이 없거나 읽을 수 없으면 출력 파일을 만들지 않고 명확한 오류를 반환한다.
- 날짜 구분선 이전의 머리말은 대화로 수집하지 않는다.
- 날짜가 설정되지 않은 메시지 형식의 줄은 보고서의 파싱 경고에 포함한다.
- 기존 출력은 모든 파싱과 검증이 성공한 뒤 교체한다.
- UTF-8 BOM 유무를 모두 처리하고 출력은 UTF-8로 통일한다.
- 사진 다운로드가 실패해도 대화 수집 결과는 유지하고 사진 상태에 실패 원인을 기록한다.
- 확장자나 대응 관계가 불확실한 사진은 추측하여 확정하지 않는다.
- 원본 파일을 덮어쓰지 않으며 같은 해시의 중복 파일은 보고서에 기록한다.

## 검증

- 여러 줄 메시지가 하나의 레코드로 생성되는지 확인한다.
- 오전 12시와 오후 12시 변환을 확인한다.
- 닉네임에 공백·괄호가 있어도 보존되는지 확인한다.
- URL과 파일 공유 기록이 보존되는지 확인한다.
- 사진이 이미지 메시지로 보존되고 동영상·이모티콘과 시스템 메시지가 제외되는지 확인한다.
- JSONL 각 줄이 유효한 JSON인지 확인한다.
- 전체 결과에서 메시지 ID가 중복되지 않는지 확인한다.
- 이미지 메시지 ID와 이미지 매니페스트가 일대일로 대응하는지 확인한다.
- 첫 사진 3개에서 날짜·시간·닉네임·순서·로컬 파일 연결을 사람이 확인한다.
- 다운로드 완료 사진의 파일 존재 여부, 크기, SHA-256을 확인한다.
- 실제 원본에 대해 참여자·메시지·제외 건수를 보고서와 대조한다.

## 컴퓨터 제어 범위

텍스트와 링크 수집에는 Windows 컴퓨터 제어가 필요하지 않다. 링크는 TXT 본문에서 직접 추출한다.

사진 원본은 Computer Use로 카카오톡 PC의 채팅방 서랍을 조작하여 다운로드하고 대화의 이미지 메시지와 연결한다. UI 자동화는 다운로드 가능한 사진을 공식 화면에서 저장하는 수단으로만 사용하며 카카오톡 내부 데이터베이스나 캐시를 직접 분석하지 않는다.

향후 첨부 문서 원본까지 필요해지면 사진 수집과 별도의 작업으로 추가한다.
