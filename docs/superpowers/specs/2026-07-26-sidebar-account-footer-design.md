# 사이드바 계정 푸터 디자인

## 목표

사이드바 아래의 사용자 정보, 로그아웃, 테마 전환을 하나의 안정된 계정 푸터로 묶는다. 지금처럼 버튼이 계단식으로 흩어져 보이지 않도록 높이·간격·정렬을 통일한다.

## 구조

- 사이드바 맨 아래에 `.sidebar-footer` 컨테이너를 둔다.
- 첫 줄에는 작은 원형 아바타와 이름, 역할을 한 덩어리로 표시한다.
- 둘째 줄에는 `로그아웃` 버튼과 테마 아이콘 버튼을 둔다.
- 로그아웃과 테마 버튼은 모두 높이 40px를 사용한다.
- 로그아웃 버튼은 남은 너비를 채우고, 테마 버튼은 40×40px 정사각형으로 표시한다.

## 시각 규칙

- 푸터는 얇은 위쪽 구분선과 충분한 위 여백으로 탐색 메뉴와 분리한다.
- 사용자 정보는 별도의 과한 알약 모양 대신 표면색 카드 안에 차분하게 배치한다.
- 역할 `관리자`는 이름보다 작은 보조 텍스트로 표시한다.
- 버튼은 기존 따뜻한 베이지 표면과 코랄 포인트 색을 사용한다.
- Noto Sans KR 상속을 유지하고 명조체나 별도 아이콘 폰트를 추가하지 않는다.

## 동작·접근성

- 로그아웃 동작과 확인 흐름은 기존 로직을 유지한다.
- 테마 버튼은 기존 달·해 SVG 및 동적 `aria-label`, `title`을 유지한다.
- 인증 정보가 준비되지 않은 동안에는 로그아웃 버튼이 빈 공간을 만들지 않는다.
- 모바일 더보기 메뉴의 계정·테마 동작은 그대로 유지한다.

## 검증 기준

- 이름·역할 영역과 버튼 영역이 한 푸터 안에 정렬된다.
- 로그아웃과 테마 버튼의 높이가 40px로 일치한다.
- 테마 버튼이 별도 줄 오른쪽에 홀로 떠 있지 않는다.
- 긴 이름에서도 레이아웃이 넘치지 않고 말줄임 처리된다.
- 키보드 포커스와 화면 읽기 프로그램용 이름이 유지된다.
