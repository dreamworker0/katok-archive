# 테마 아이콘 전환 디자인

## 목표

기존의 `다크 모드`·`라이트 모드` 텍스트 버튼을 따뜻한 아카이브 화면에 어울리는 선형 아이콘 버튼으로 바꾼다. 데스크톱과 모바일에서 같은 의미와 동작을 제공한다.

## 표시 규칙

- 현재 화면이 라이트 모드이면 달 아이콘을 표시한다. 누르면 다크 모드로 전환된다.
- 현재 화면이 다크 모드이면 해 아이콘을 표시한다. 누르면 라이트 모드로 전환된다.
- 아이콘은 외부 라이브러리나 이미지 파일 없이 인라인 SVG로 렌더링한다.
- 데스크톱 버튼은 사이드바 아래에서 36×36px 아이콘 버튼으로 표시한다.
- 모바일 더보기 메뉴에도 같은 SVG 아이콘을 사용하되, 의미를 빠르게 알 수 있도록 접근성 이름을 유지한다.

## 접근성

- 아이콘 자체는 `aria-hidden="true"`로 처리한다.
- 버튼의 `aria-label`과 `title`은 전환 대상에 따라 `다크 모드로 전환` 또는 `라이트 모드로 전환`으로 갱신한다.
- 키보드 포커스와 기존 클릭 영역은 유지한다.

## 동작

기존의 테마 선택, 시스템 테마 감지, `localStorage` 저장 로직은 그대로 사용한다. `updateThemeControls()`가 현재 테마를 읽어 해·달 SVG와 접근성 문구만 함께 갱신한다.

## 검증

- 라이트 모드에서 달 아이콘과 `다크 모드로 전환` 설명이 일치한다.
- 다크 모드에서 해 아이콘과 `라이트 모드로 전환` 설명이 일치한다.
- 데스크톱·모바일 컨트롤이 같은 규칙을 따른다.
- 아이콘에 표시용 텍스트가 노출되지 않으며 키보드와 화면 읽기 프로그램에서 의미가 유지된다.
