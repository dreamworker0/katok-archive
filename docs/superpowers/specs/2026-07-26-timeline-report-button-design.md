# 타임라인 보고서 버튼 디자인

## 목표

타임라인 카드의 핵심 동작인 `보고서 읽기`를 링크처럼 작은 텍스트가 아니라 명확한 기본 버튼으로 표현한다.

## 디자인

- 문서 선형 아이콘과 `보고서 읽기` 문구를 함께 표시한다.
- 높이는 최소 40px, 글자는 14px 굵게 사용한다.
- 따뜻한 포인트색의 옅은 배경과 테두리를 사용해 반복 카드 안에서도 과도하게 무겁지 않게 강조한다.
- 보고서가 열리면 문구를 `보고서 접기`로 변경한다.
- `.md` 저장 버튼은 오른쪽의 작은 보조 동작으로 유지한다.

## 접근성 및 검증

- 문서 아이콘은 `aria-hidden="true"`로 처리한다.
- 버튼의 `aria-expanded`를 실제 보고서 펼침 상태와 동기화한다.
- 키보드 포커스와 기존 클릭 동작을 유지한다.
- 데스크톱과 모바일 모두 최소 40px 높이를 유지한다.
